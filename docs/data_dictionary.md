# Словарь данных (Data Dictionary) — Проект «Modify»

Каталог игровых модификаций `Modify`: таблицы данных для анализа с помощью `pandas`, `numpy` и `matplotlib`.

Набор данных состоит из **3 компактных CSV-таблиц** в папке `data/`:
1. `mods.csv` — основной каталог модов
2. `comments.csv` — отзывы и комментарии пользователей
3. `users.csv` — пользователи и авторы платформы

---

## 1. Таблица `mods.csv` (Каталог модификаций)
Файл содержит ключевую информацию о модах, доступных на платформе.

| Поле | Тип данных | Описание | Пример значения |
| :--- | :--- | :--- | :--- |
| `mod_id` | `int` | Уникальный ID мода (Primary Key) | `1`, `42` |
| `title` | `string` | Название модификации | `4K Текстуры высокого разрешения v2.0` |
| `game` | `string` | Игра (Skyrim, The Witcher 3, Cyberpunk 2077, Minecraft и др.) | `The Witcher 3` |
| `category` | `string` | Категория (Графика, Геймплей, Патчи, Интерфейс, Русификаторы и т.д.) | `Графика и визуал` |
| `author` | `string` | Имя/никнейм автора мода | `GeraltCraft` |
| `downloads` | `int` | Количество скачиваний (лог-нормальное распределение) | `12450` |
| `rating` | `float` | Средний рейтинг мода (от 1.0 до 5.0) | `4.65` |
| `has_instructions` | `bool` | Наличие понятной инструкции по установке в описании (`True` / `False`) | `True` |
| `description` | `string` | Описание мода, включая текст инструкции по установке | `Пак HD-текстур. Инструкция по установке: распаковать...` |
| `upload_date` | `string (YYYY-MM-DD)` | Дата загрузки мода на платформу | `2024-04-12` |

---

## 2. Таблица `comments.csv` (Комментарии и отзывы)
Отзывы игроков под карточками модов.

| Поле | Тип данных | Описание | Пример значения |
| :--- | :--- | :--- | :--- |
| `comment_id` | `int` | Уникальный ID комментария | `1`, `105` |
| `mod_id` | `int` | ID мода, к которому оставлен комментарий (Foreign Key -> `mods.mod_id`) | `42` |
| `username` | `string` | Имя пользователя, оставившего отзыв | `Alex_Gamer_23` |
| `text` | `string` | Текст комментария (благодарность, вопрос или жалоба на ошибку) | `Установил за пару минут благодаря инструкции, респект!` |
| `rating` | `int` | Оценка мода от пользователя (от 1 до 5) | `5` |
| `date` | `string (YYYY-MM-DD)` | Дата публикации отзыва | `2024-05-01` |

---

## 3. Таблица `users.csv` (Пользователи платформы)
Учетные записи сообщества.

| Поле | Тип данных | Описание | Пример значения |
| :--- | :--- | :--- | :--- |
| `user_id` | `int` | Уникальный ID пользователя | `1` |
| `username` | `string` | Никнейм | `NordicDev` |
| `role` | `string` | Роль на платформе: `автор` или `игрок` | `автор` |
| `registration_date` | `string (YYYY-MM-DD)` | Дата регистрации | `2023-06-18` |
